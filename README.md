# MatchLens

Zaseban nogometni projekt. Javni repozitorij izričito je odobren 28.10.2026.; objavljena aplikacija ostaje privatna.

Ovaj početni prijenos sadrži samo izvorne datoteke funkcionalnosti MatchLensa, shemu i razvojni plan. Platformska infrastruktura, hosting konfiguracija, autentikacijski predlošci i tajne nisu uključeni. Ovo još nije samostalno izvršiv paket: potrebno je dodati odgovarajuće razvojno okruženje i integracije za autentikaciju i bazu.

Automatski izvori i trenirani model nisu povezani. Pročitati CLAUDE.md i docs/PLAN_IZRADE.md prije rada. Pripremljene upute ne znače da je Claude pokrenut.
